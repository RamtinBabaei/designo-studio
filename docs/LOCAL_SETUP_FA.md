# راهنمای اجرای پروژه در ویندوز و VS Code

۱. Node.js نسخه ۲۴ و Git را نصب کنید. این نسخه از پروژه با Node 24.19.0 تست شده است.

۲. فایل ZIP را Extract کنید. پیشنهاد می‌شود پروژه را در مسیری کوتاه مثل `C:\Projects\designo-studio` قرار دهید.

۳. در VS Code از File → Open Folder پوشه‌ای را باز کنید که فایل `package.json` داخل آن است.

۴. از Terminal → New Terminal یک ترمینال باز کنید. دستورهای زیر را **جداگانه** اجرا کنید:

```powershell
node --version
npm.cmd install --global pnpm@11.25.0
pnpm.cmd install --frozen-lockfile
pnpm.cmd setup:local
pnpm.cmd dev
```

۵. لینک Local که ترمینال نشان می‌دهد را باز کنید. در اجرای معمولی آدرس `http://localhost:5173` است. ترمینال باید باز بماند. نیازی به MongoDB، نصب SQL Server، ورود به Cloudflare یا API Key ندارید. دیتابیس محلی خودش ساخته می‌شود.

## تست فرم و صفحات

- صفحه اصلی، Our Company، Locations و هر سه دسته خدمات را باز کنید.
- روی یک پروژه بزنید؛ پنجره جزئیات را باز کنید و با Escape ببندید.
- در صفحه Contact بدون تکمیل فرم Submit بزنید؛ خطای فیلدها باید مشخص شود.
- با اطلاعات آزمایشی، ایمیل معتبر و متن حداقل ۱۰ کاراکتر پیام ارسال کنید. باید شناسه ثبت نمایش داده شود.
- موفقیت یعنی پیام داخل دیتابیس ذخیره شده است. این پروژه ایمیل ارسال نمی‌کند؛ این موضوع داخل فرم هم نوشته شده است.
- در عرض موبایل، منو باید باز و بسته شود. همه صفحه‌ها و فرم را با کیبورد نیز بررسی کنید.

در یک ترمینال دوم تست‌ها را اجرا کنید:

```powershell
pnpm.cmd typecheck
pnpm.cmd test
pnpm.cmd check:assets
pnpm.cmd test:http http://localhost:5173
```

تست HTTP نیاز دارد ترمینال `dev` همچنان در حال اجرا باشد. یک پیام آزمایشی در دیتابیس محلی ثبت می‌کند. محدودیت فرم ۵ پیام در ۱۵ دقیقه برای هر شبکه است؛ بعد از رسیدن به محدودیت، منتظر بمانید.

## اجراهای بعدی

```powershell
pnpm.cmd dev
```

اگر خطای `no such table: inquiries` دیدید:

```powershell
pnpm.cmd setup:local
```

اگر نصب اینترنتی قطع شد، همان دستور نصب را دوباره اجرا کنید. خطاهای نصب را با حذف تصادفی فایل‌های پروژه یا جایگزینی lockfile برطرف نکنید. `node_modules` و پوشه‌های مخفی وضعیت اجرای یک کامپیوتر دیگر را به پروژه منتقل نکنید.

## بیلد نهایی

```powershell
pnpm.cmd build
pnpm.cmd start
```

آدرس چاپ‌شده را باز کنید. این برنامه بک‌اند دارد؛ برای نسخه کامل نمی‌توان فقط پوشه خروجی را به GitHub Pages فرستاد. GitHub برای کد و CI مناسب است؛ دستور استقرار Cloudflare در DEPLOYMENT.md آمده است.
